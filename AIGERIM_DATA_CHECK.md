# Проверка выгрузки Айгерим и начальная подборка кадров Барнарда

Проверено 14 ноября 2026 года. Пользователь сообщил, что целевой объект выгрузки с Айгерим не уточняли. Поэтому исходный файл не считается согласованным списком наблюдений звезды Барнарда.

## Что находится в исходном файле

Исходник: локальный файл `table_Spectral-Images (1).tbl`, не включённый в репозиторий. Файл не изменён. Его SHA-256 сохранён в [selection.json](data/irsa_barnard_20261114/selection.json).

| Свойство | Результат чтения файла |
| --- | --- |
| Формат | Текстовая таблица IPAC, 60 столбцов |
| Записи продуктов | 372 |
| Уникальные `obs_id` | 188; одно наблюдение может иметь несколько детекторов |
| Выпуски | `spherex_dr1`: 265 строк; `spherex_qr3`: 107 строк |
| Детекторы | D1–D6 |
| Временное покрытие по `t_min`/`t_max` | 17 сентября 2025 — 4 октября 2026 года |
| Центры кадров, RA | 294.32186906° … 298.26898590° |
| Центры кадров, Dec | −16.67792059° … −12.85175631° |
| Обязательные поля | `obs_id`, `obs_collection`, `energy_bandpassname`, `t_min`, `t_max`, `access_url`, `s_region` заполнены во всех строках |

Все интервалы имеют правильный порядок начала и конца. Даты создания и публикации файлов отличаются от времени наблюдения; для расчёта нужны `t_min`/`t_max` либо соответствующие поля FITS.

### Покрытие звезды Барнарда отсутствует

Ближайший центр кадра находится в **30.6603°** от каталожной позиции Барнарда при J2016.0. Максимальное расстояние от центра кадра до его угла среди всех 372 записей составляет **2.5406°**. Движение Барнарда за рассматриваемые годы составляет доли градуса и не устраняет это расхождение. Границы `s_region` не покрывают нужную звезду.

### Вероятная причина: галактика Барнарда

[SIMBAD: NGC 6822](https://simbad.harvard.edu/simbad/sim-id?Ident=NGC+6822) содержит имя **Barnard's Galaxy** и координаты ICRS RA=296.2341625°, Dec=−14.79758056°. Центр этой галактики лежит внутри **370 из 372** границ кадров исходной выгрузки; два остальных кадра проходят в пределах 22″ от центра. Это соответствует полю галактики Барнарда. Размер галактики заметно больше этих смещений; [NASA также использует имя Barnard's galaxy для NGC 6822](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-caldwell-catalog/caldwell-57/).

**Вывод о возможной путанице имён — предположение по координатам.** Исходный запрос Айгерим неизвестен, поэтому нельзя утверждать, какое имя было введено в поиске. Для дальнейшего поиска звезды следует использовать проверенный идентификатор **Gaia DR3 4472832130942575872 / GJ 699**.

### Ссылки на файлы

В исходной таблице `access_format` указывает DataLink, поэтому `access_url` возвращает список доступных продуктов. Для первой строки запрос выполнен: ссылка с `semantics=#this` ведёт на научный FITS-файл. У него проверен заголовок расширения IMAGE: `TIMESYS=UTC`, `RADESYS=ICRS`, `DETECTOR=6`; `DATE-BEG=2025-09-17T09:44:11.768`, `MJD-BEG=60935.405691759`. Это проверка структуры файла из другой области неба, а не наблюдения Барнарда. [Правила доступа DataLink в SIA](https://ivoa.github.io/IvoaDocViewSite/idoc/SIA/SIA.html#use-of-access-url-and-access-format).

## Отдельно найденные наблюдения звезды Барнарда

Чтобы подготовка расчёта не зависела от неуточнённой выгрузки, выполнен самостоятельный запрос [IRSA SIA](https://irsa.ipac.caltech.edu/ibe/sia.html): коллекции DR1 и QR3, калиброванные изображения, круг радиуса 0.05° вокруг исходной позиции Gaia при J2016.0. Круг включает последующее движение звезды в интервале доступных наблюдений.

Запрос вернул **378 кандидатов**, статус `QUERY_STATUS=OK`, без усечения. После переноса положения Барнарда на среднее время каждого кадра **358** предсказанных положений оказались внутри сферических многоугольников `s_region` с запасом более 10″ до края. Проверка учитывает собственное движение; годичный параллакс не применён. Выборка охватывает 15 августа 2025 — 22 сентября 2026 года. Это результат поиска на дату проверки, не обещание полноты архива.

Для начала выбраны три продукта **одного детектора D1 и одного выпуска DR1**. Взяты первая и последняя доступные безопасные даты DR1/D1 и дата, ближайшая к середине интервала; внутри каждой даты выбран наибольший запас до границы кадра.

| ID наблюдения | Среднее время UTC из FITS `DATE-AVG` | `MJD-AVG` UTC | Детектор / выпуск |
| --- | --- | ---: | --- |
| `2025W35_1A_0432_4` | 2025-08-27 05:07:00.174 | 60914.213196455 | D1 / DR1 |
| `2025W40_1A_0471_1` | 2025-10-01 03:08:33.664 | 60949.130945182 | D1 / DR1 |
| `2026W11_1A_0539_2` | 2026-03-11 13:36:50.027 | 61110.567245680 | D1 / DR1 |

У всех трёх научных FITS проверены `TIMESYS=UTC`, `RADESYS=ICRS`, `DETECTOR=1`, размер IMAGE 2040×2040. `DATE-AVG` согласуется с `MJD-AVG` в пределах 1 ms. Для точного входного времени использован **`MJD-AVG` заголовка**, а не округлённая середина интервала архивного поиска. При чтении через пространственную привязку WCS предсказанная позиция попадает внутрь каждого IMAGE. Координаты пикселей и поля заголовка сохранены в `selection.json`; это проверка покрытия, а не измерение звезды на изображении.

## Подготовленные файлы

- [observations.csv](data/irsa_barnard_20261114/observations.csv) — три реальных наблюдения в формате входа существующего расчёта; есть точные времена, идентификаторы, D1, DR1 и прямые ссылки FITS; `is_demo=false`.
- [barnard_positions_irsa.csv](output/barnard_positions_irsa.csv) — барицентрические астрометрические RA/Dec на эти времена с формальными ошибками Gaia, рассчитанные существующим `barnard_motion.py`.
- [search_results.vot](data/irsa_barnard_20261114/search_results.vot) — исходный ответ IRSA, 378 записей.
- [selection.json](data/irsa_barnard_20261114/selection.json) — воспроизводимый URL запроса, правила выбора, контрольные суммы, метаданные и проверки покрытия.
- Три файла `*_image_header.txt` в той же папке — сохранённые заголовки IMAGE выбранных кадров. Полные изображения, потоки и маски не загружались.

| --- | ---: | ---: |
| `2025W35_1A_0432_4` | 269.446344534180 | +4.767221894312 |
| `2025W40_1A_0471_1` | 269.446323148246 | +4.767497402397 |
| `2026W11_1A_0539_2` | 269.446224270495 | +4.768771209715 |

Между первым и последним моментом прошло **196.354049 дня**. В выбранной модели ожидается смещение **5.594198″**. Это предсказание по Gaia, а не измеренный сдвиг.

В прогнозе стоит `parallax_applied=false`; характерный масштаб параллакса для базы 1 а.е. составляет около **0.5473″**. Формальные ошибки положения порядка 0.3–0.4 mas описывают только распространённые ошибки исходных параметров в принятой модели. Они не включают неприменённую поправку за параллакс, точность привязки изображения, ошибки центроида или особенности яркого источника.

Повторный запуск из папки проекта:

```sh
uv run --locked barnard_motion.py --observations data/irsa_barnard_20261114/observations.csv --output output/barnard_positions_irsa.csv
```

Это **самостоятельно найденный начальный список**, не подтверждённый выбор команды Айгерим. Для научного сравнения дальше нужны сами изображения, проверка флагов и измеренных центров, а также согласование параллактической поправки с пространственной привязкой кадров. Один номер детектора не гарантирует одинаковую спектральную полосу в разных положениях на нём.
