  47 входов, 36 сценариев `/api/view`, 188 кадров, 0 запросов данных к IRSA.
  Хеши входов и сохранность SOURCE проверены скриптом `scripts/accept_processing.py`.
- `browser.json` — управляемые синтетические браузерные сценарии на фронтенде

  кандидатов и адаптивности, без нового живого архива/проверки другого устройства.

  Числа из этих файлов не удостоверяют точность всех восьми целей/43+4 кадров.
