## Доказательства и воспроизведение

[replay.json](../../data/validation/processing-acceptance/replay.json) записан на
`be2ca1a`. Это новый прогон **47 сохранённых входов** (43 кадра восьми целей и
4 вырезки точных координат WISE), **36 сценариев `/api/view`** и **188 кадров**:
по четыре режима `single`, `coadd`, `diff`, `trail` для девяти запросов.
Проверены HTTP 202→200, получение PNG изображений/флагов/следов, сериализация,
источники времени, полосы, качество и отсутствие измеренной скорости.

Запросы выполнены через FastAPI TestClient с настоящими маршрутом, очередью,
загрузчиком FITS, обработкой и выдачей PNG. Подменены **только входы архива**:
список выбранных продуктов, получение уже сохранённой вырезки и транспорт Sesame.
Готовый `result.json` не подставлялся. Результаты и PNG построены заново в пустой
временной папке, общий кэш использовался только для чтения FITS.
**Новых запросов данных к IRSA: 0.** Бюджет запросов TestClient увеличен только
в процессе проверки; производственный ограничитель проверен отдельными тестами.
Это не новое испытание живой доступности архива или холодного сетевого старта.
Отдельно повторены управляемые браузерные сценарии и новые подписи на фронтенде `b67c60b`
(в `be2ca1a` он тот же): [browser.json](../../data/validation/processing-acceptance/browser.json).
Проверены кандидат в 16.9 px от прогноза, легенда отсутствующих данных, сохранение предупреждений,
смена дат и ширины 1440/768/375 px (изображения 560/560/351 px). Это синтетические
браузерные входы, не новый живой просмотр восьми звёзд и не проверка другого устройства.

Повторить из корня проекта с сохранёнными вырезками:

```sh
uv run --offline --locked python scripts/accept_processing.py \
  --fits-cache "$SPHEREX_SAVED_FITS" --output /tmp/processing-replay.json
uv run --offline --locked pytest -q
git diff --check
```

`SPHEREX_SAVED_FITS` — папка проверяющего с `cut_*.fits`, а не личный путь автора.
На другом компьютере скрипт сообщает число отсутствующих файлов. Явный параметр
`--download-limit 47` разрешает максимум 47 однократных загрузок точных URL из
манифеста в указанную папку, без поиска архива и повторов. По умолчанию сеть для
данных отключена. SHA-256 каждого файла обязателен: изменённый сервером продукт
не считается тем же свидетельством. В этой приёмке параметр загрузки не использовался.

`replay.json` содержит проверенные obs_ids, детекторы, выпуски, SHA-256 FITS,
MJD UTC, локальные флаги и полные новые ответы API. Продукты и URL находятся в
[научном манифесте](../../data/validation/science-acceptance/evidence.json).
Научные исходники и сохранённые API-ответы защищены проверками хешей.

## Регистрация и разрешённые выводы

На `be2ca1a` в `processing.registration` явно записано:
`header_wcs_reprojection`, `independently_verified=false`,
`astrometric_precision_arcsec=null`. Пересчёт тем же WCS и тем же предиктором,
включая прежний предел ошибки маркера 0.000488 px и запас ≥7 px, проверяет
арифметику/покрытие, **не независимую регистрацию**. Полного независимо
проверенного предела точности по опорным звёздам для всех восьми целей и именно этой
выборки нет. Вместе с `246603f` сохранены `registration_gaia.json` и
`registration_relative.json`: это дополнительная эмпирическая диагностика меньших
вырезок/частичных полей. Она не повторялась в этом прогоне, не хранит полный исходный
ответ Gaia и использует другой каталожный адаптер и упрощённый перенос без полного
согласования параллакса/эпох/систематик. Её оценки не перенесены на все 43+4 кадра
и не приняты здесь как сертификация измерений. См. README рядом с данными.
Признаки `poor`, неоднозначные кандидаты и реальные маски не позволяют принять
шумовые `err_px` за полную ошибку положения.

[Первичная документация IRSA](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-products/)
указывает, что IMAGE содержит зодиакальный фон, а WCS-WAVE предназначен для
визуализации; научный спектральный анализ использует CWAVE/CBAND калибровочного
продукта. Текущие ZODI, маски и подписи λ достаточны для оговорённого просмотра,
но сами по себе не сертифицируют поток/спектральный индекс/переменность.

| Пригодность | Что принято на `be2ca1a` | Что остаётся за пределами |
| --- | --- | --- |
| **Визуальный просмотр** | Реальные участки восьми звёзд и точных координат WISE; даты/obs_ids/локальные полосы; маски и отсутствие покрытия; diff/trail как относительная визуальная диагностика; каталоговый ориентир пяти целей | Не гарантируется обнаружение каждой цели и интерпретация каждого видимого остатка как изменения неба |
| **Измерения** | Каталожные параметры и вычисленный по ним прогноз с описанными допущениями; технические центроиды кандидатов с формальными шумовыми ошибками можно исследовать | Ни один набор целевых центроидов/потоков не принят для количественного движения, параллакса, амплитуды или периода. Нужны независимая регистрация, ассоциация, пригодные маски и согласованные полосы/отклики/ошибки |
| **Нельзя утверждать** | — | Измеренное движение/переменность; обнаружение WISE или каждой слабой цели; разрешение Ba/Bb или RW Aur A/B; отдельную фотометрию RW Aur A; измеренный период R Dra; обнаружение метана; калиброванную σ-значимость diff; независимую регистрацию; полноту/свежесть текущего архива |

Новые PSF-модели и количественные измерения для этой области Б1 не требуются.
Если заявленная возможность расширяется до измерений, ограниченное согласование
Б1 её автоматически не покрывает.

## Решение по Д2–Д7 и оставшиеся задачи

- **Д2.1–6** закрываются для пяти каталожных целей и проверенного Sesame-сценария;
  неизвестные эпохи/шкалы остаются неизвестными.
- **Д3.1–6** закрываются для общей модели, времени, геометрии сетки и покрытия
  выбранных кадров; независимая регистрация/измерительная точность не входят в это закрытие.
- **Д4.1–6** закрываются как контракт статусов, качества, кандидатов и предупреждений;
  спектральные измерения на реальных данных не сертифицированы.
- **Д5.1–9** закрываются по прежним браузерным свидетельствам, повтору управляемого
  сценария и новым проверкам подписей/предупреждений в browser.json.
- **Д6** закрывается как воспроизводимый просмотр пяти NASA-целей, трёх дополнительных
  звёзд и отдельного точного координатного запроса WISE на выбранных сохранённых данных.
- **Д7** закрывается как объединение, проверки и документированная передача этой ветки;
  личные согласования участников не выдумываются.
- **Б1** согласован с перечисленными ограничениями. Б2 сохраняет прежнюю
  API-приёмку для одного процесса, её регрессии проходят. **Постоянное размещение Б3
  остаётся отдельной задачей**; новую публикацию этой версии и весь objective не объявляем завершёнными.
