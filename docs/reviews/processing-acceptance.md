## Что пригодно для визуальной демонстрации

- Последовательность реальных кадров SPHEREx по датам на общей сетке «север вверху», с вычтенным ZODI и
  остаточным фоном; маски применены до интерполяции; «нет данных» отличимо от неба; слой флагов не закрашивает SOURCE.
- Режимы `coadd`/`single`, «мигание» по эпохам длиной ≤ 20 сут, маркер прогноза по каталогу.
- `diff` и `trail` как **качественная** картина: красное/синее — «ярче/темнее, чем в остальных эпохах»,
  в шкале `robust_residual_scale`. При разных каналах (сейчас у всех проверенных целей) пользователь получает предупреждение.
- Центр с `measured_px` как подпись «кандидат совпадает с прогнозом в пределах 1 пикс.»; кандидаты — как кандидаты.

## Что пригодно для количественного измерения (с указанными ошибками)

- Положение изолированной, ненасыщенной звезды в отдельном кадре там, где есть ≥3 опорные звезды Gaia:
  ±0.1–0.15 пикс. (0.6–0.9″) случайно, плюс систематика WCS экспозиции до 0.4 пикс. (2.4″).
  Проверено для полей D3 (eps Ind B, Барнард) и D2 (RW Aur).
- Апертурный поток ненасыщенной цели в одной экспозиции с `ok=true` (eps Ind B: S/N ~100) — как
  **неоткалиброванная** величина в мкЯн без апертурной поправки, с ошибкой «пиксели + медиана кольца».
- Сравнение потоков **только** внутри одного спектрального канала (`different_channels=false`).

## Какие утверждения пока делать нельзя

- **Измеренное собственное движение** любой из пяти целей: Барнард насыщен (центр ошибается на 0.6–2.9 пикс.,
  `measured_px=null` во всех кадрах), WISE 0855 не обнаружен в отдельных экспозициях D6 (1 из 18) и его поле не
  имеет опорных звёзд, у eps Ind B кадры неоднозначны и Ba/Bb не разрешены. Совпадение кандидата с прогнозом —
  не независимое измерение движения.
- **Переменность** RW Aur и R Dra (и любой цели): апертура насыщена/замаскирована во всех 38 реальных точках;
  кадры разных эпох сняты в разных спектральных каналах. Период R Dra не измерялся.
- **Статистическая значимость** остатков diff («обнаружено на Nσ»): шкала `robust_residual_scale` не
  откалибрована (корреляции интерполяции, шаблон из тех же данных).
- **Движение по diff при сдвиге меньше ~5 пикс. между центрами долей** — в том числе Барнард за полгода:
  такие центры смещены и не выдаются.
- **Обнаружение WISE 0855** в конкретной экспозиции/канале и **метановый индекс**.
- **Точность регистрации** для полей R Dra (D2) и WISE 0855 (D6) — не проверена из-за отсутствия опорных звёзд.
- **Абсолютные потоки/спектры** в физических единицах с полной ошибкой: нет апертурной поправки, калибровки,
  ошибки положения и формы канала.
- Что повтор подтверждает свежую выборку архива: IRSA был недоступен; использованы те же obs_id из кэша.
